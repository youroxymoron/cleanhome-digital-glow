# Цели Яндекс Метрики для cleanhousednr.ru

## Рекомендуемые цели типа «Целевое событие»

В Метрике откройте **Настройки → Цели → Добавить цель → Целевое событие**. Для каждой цели выберите условие **совпадает** и укажите идентификатор из таблицы.

| Название цели | Идентификатор | Когда срабатывает |
|---|---|---|
| Успешная отправка заявки | `contact_form_submit` | Только после успешной отправки заявки в Telegram или MAX |
| Клик по телефону | `phone_click` | Клик по любому номеру в шапке, меню, контактах или футере |
| Клик по email | `email_click` | Клик по адресу электронной почты |
| Переход к контактам | `contact_cta_click` | Клик по кнопке заказа или записи, ведущей к форме |
| Заказ со страницы услуги | `service_order_click` | Клик «Заказать услугу» на детальной странице |
| Открытие услуги | `service_detail_click` | Переход в карточку конкретной услуги |
| Переход к списку услуг | `services_cta_click` | Клик по кнопкам «Наши услуги» или «Все услуги» |
| Дополнительная контактная ссылка | `contact_link_click` | Клик по дополнительной ссылке в контактах |

Для главной конверсии используйте именно событие `contact_form_submit`, а не автоматическую цель отправки формы: программное событие вызывается только после ответа сервера об успешной доставке заявки.

## HTML ID для выбора элементов в интерфейсе Метрики

### Форма

- Форма: `#contact-request-form`
- Поле имени: `#contact-name`
- Поле телефона: `#contact-phone`
- Поле сообщения: `#contact-message`
- Кнопка отправки: `#contact-form-submit`

### Основные CTA-кнопки

- Главная кнопка первого экрана: `#cta-hero-order`
- Кнопка «Наши услуги»: `#cta-hero-services`
- Кнопка заказа в блоке услуг: `#cta-services-order`
- Кнопка заказа в галерее: `#cta-gallery-order`
- Кнопка записи в шапке: `#cta-header-booking`
- Мобильная кнопка записи: `#cta-header-mobile-booking`
- Кнопка со страницы списка услуг: `#cta-services-page-contact`
- Кнопка на странице конкретной услуги: `#cta-service-order`

### Разделы страницы

- Первый экран: `#hero`
- Услуги: `#services`
- Отзывы: `#reviews`
- Галерея: `#gallery`
- О компании: `#about`
- Вопросы и ответы: `#faq`
- Контакты: `#contacts`
- Футер: `#footer`

У динамических контактов ID содержит постоянный UUID записи из админки, например `#contact-link-<uuid>` и `#footer-contact-<uuid>`. Для объединённой статистики удобнее использовать события `phone_click` и `email_click`, а расположение клика смотреть в параметре `placement`.
