# Публикация cleanhousednr.ru и настройка Яндекс Вебмастера

## 1. Публикация архива на Timeweb

1. В панели Timeweb возобновите услугу хостинга для `cleanhousednr.ru`, если она приостановлена.
2. Подключите и проверьте SSL-сертификат для `cleanhousednr.ru` до публикации. Перенаправление HTTP на HTTPS выполняется настройками Timeweb.
3. Откройте файловый менеджер и найдите корневой каталог домена. Обычно это `public_html`, но точный каталог указан в настройках домена Timeweb.
4. Сохраните резервную копию текущего содержимого каталога.
5. Удалите старое содержимое корня сайта после создания резервной копии. Особенно важно удалить старые каталоги `services`, `privacy` и `offer`: они вызывают циклические редиректы на Timeweb.
6. Загрузите актуальный архив `cleanhousednr.ru-timeweb-2026-08-21-v4.zip` в пустой корневой каталог домена и распакуйте его прямо туда. В корне должны оказаться `index.html`, `.htaccess`, `robots.txt`, `sitemap.xml`, папки `assets`, `images` и `_prerender`. Каталогов `services`, `privacy` и `offer` быть не должно.
7. Проверьте права: для файлов обычно `644`, для каталогов `755`.
8. Если в панели включено кеширование, очистите кеш сайта.

Node.js на хостинге не требуется: в архиве находится готовый статический сайт.

### Проверка после загрузки

Откройте в приватном окне браузера:

- `https://cleanhousednr.ru/` — ответ 200, главная страница.
- `https://cleanhousednr.ru/services` — ответ 200, список услуг.
- `https://cleanhousednr.ru/robots.txt` — ответ 200, текстовый файл.
- `https://cleanhousednr.ru/sitemap.xml` — ответ 200, XML-карта сайта.
- `http://cleanhousednr.ru/` — перенаправление 301 на HTTPS.
- `https://www.cleanhousednr.ru/` — перенаправление 301 на адрес без `www`.
- `https://cleanhousednr.ru/proverka-404` — ответ именно 404, не 200.

После добавления или удаления услуги через админ-панель нужно снова выполнить `npm run build` и опубликовать новую сборку: prerender-файлы и sitemap создаются во время сборки.

## 2. Добавление сайта в Яндекс Вебмастер

1. Откройте `https://webmaster.yandex.ru/` и добавьте сайт `https://cleanhousednr.ru/`.
2. В разделе **Настройки → Права доступа** выберите подтверждение HTML-файлом — это самый удобный вариант для данного хостинга.
3. Скачайте предложенный файл вида `yandex_XXXXXXXX.html`, загрузите его в тот же каталог, где находится `index.html`, проверьте его открытие по HTTPS и нажмите **Подтвердить**.
4. Не удаляйте проверочный файл после подтверждения: Яндекс периодически перепроверяет права.

## 3. Обязательные проверки в Вебмастере

1. **Инструменты → Проверка ответа сервера**:
   - главная и публичные страницы должны возвращать `200 OK`;
   - HTTP и `www` должны давать один последовательный `301` на `https://cleanhousednr.ru/...`;
   - случайный несуществующий URL должен возвращать `404`;
   - `/robots.txt` и `/sitemap.xml` должны возвращать `200 OK`.
2. **Инструменты → Анализ robots.txt**: загрузите текущий файл и проверьте, что главная и `/services` разрешены, а `/admin` и `/auth` запрещены.
3. **Инструменты → Анализ файлов Sitemap**: проверьте `https://cleanhousednr.ru/sitemap.xml`.
4. **Индексирование → Файлы Sitemap**: добавьте `https://cleanhousednr.ru/sitemap.xml`.
5. **Индексирование → Рендеринг страниц JavaScript**: выберите запрет/отключение дополнительного JS-рендеринга. Контент уже находится в HTML благодаря prerender.
6. **Представление в поиске → Региональность**: укажите `Донецк`, если он доступен в списке; иначе выберите наиболее точный доступный регион обслуживания.
7. **Представление в поиске → Организации**: привяжите или создайте карточку Clean House в Яндекс Бизнесе. Телефон, график, адрес/зона обслуживания и URL сайта должны совпадать с сайтом.
8. **Оптимизация сайта → Диагностика сайта**: исправьте критические ошибки после первого обхода.
9. **Индексирование → Мониторинг важных страниц**: добавьте главную, `/services` и основные коммерческие страницы услуг; включите уведомления.
10. Подключите существующий счётчик Яндекс Метрики и проверьте, что визиты и SPA-переходы фиксируются.
